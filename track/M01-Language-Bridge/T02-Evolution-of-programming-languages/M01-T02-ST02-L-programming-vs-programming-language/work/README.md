# Programming vs Programming Language

## What is Programming?
- Programming is the process of writing instructions for a computer to execute.

## What is Programming Language?
- Programming Language is a language used to write instructions for a computer to execute.

## What is Java?
- Java is a High Level Programming language created by James Gosling in 1995.
- java was created in sun microsystem of greenteam of 12 members.later bought it by Oracle. 

## What is Syntax?
- Syntax is nothing but the rules of programming language.

## Programming and java
- Programming means giving instructions to the computer to execute.
- Java is a programming language used to communicate to the computer to execute the task.
## What Remained the Same?
- Logic remains same between pseudocode and java

## What Changed?
-  Only Syntax is changed when the pseudocode is converted to java code.
